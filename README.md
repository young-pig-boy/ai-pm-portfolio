# AI 产品经理项目作品集

## 本地预览

在当前目录的上一级运行静态服务器，然后访问：

- 作品集首页：`http://localhost:8080/作品集/`
- SnackOps：`http://localhost:8080/作品集/snackops/`
- 简历专家：`http://localhost:8080/作品集/resume-expert/`

## GitHub Pages

本仓库仅包含经过脱敏处理的静态作品集，不包含项目源代码、API Key、手机号、私人邮箱或本地配置文件。开启 GitHub Pages 后可访问：

- `/snackops/`
- `/resume-expert/`

对外投递时，联系方式以简历为准。简历中建议写成：`项目作品集：总览链接｜SnackOps｜简历专家`。

## 源码公开原则

两个完整项目暂不放入本公开仓库。若后续单独公开源码，应先移除 `.env`、`config.local.js`、API Key、访问令牌、私人测试数据和调试链接，并提供 `.env.example` 说明配置项。
